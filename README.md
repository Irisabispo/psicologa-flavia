# Landing Page - Psicóloga Flávia Custódio
## Tecnologias
- HTML5
- CSS3
- JavaScript Vanilla

## Funcionalidades
- Layout responsivo para desktop, tablet e mobile
- Menu mobile com acessibilidade (aria-expanded e fechamento via ESC)
- Formulário de solicitação de agendamento
- Validação de e-mail no JavaScript
- Máscara automática para telefone
- Integração com WhatsApp
- Botão flutuante de WhatsApp
- Google Maps incorporado
- Feedback visual para envio do formulário
- Atualização automática do ano no rodapé

## Acessibilidade
- Estrutura semântica com nav, main, section e footer
- aria-label
- aria-expanded
- aria-controls
- role="status"
- aria-live="polite"
- Navegação por teclado

## Segurança
- Content Security Policy (CSP)
- Proteção com rel="noopener noreferrer"
- Bloqueio de object-src
- Restrição de base-uri


## Performance
- Fontes locais com @font-face
- Lazy loading de imagens
- Arquivos separados por responsabilidade (HTML, CSS e - JavaScript)
- Font-display: swap
