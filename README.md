# Landing Page - Psicóloga Flávia Custódio

## Estrutura dos arquivos

```
landing-flavia-custodio/
├── index.html      → Estrutura HTML
├── styles.css      → Estilos CSS (separado)
├── script.js       → JavaScript (botões)
└── README.md       → Este arquivo
```

## 🚀 Como usar

1. Baixe os 3 arquivos (`index.html`, `styles.css`, `script.js`) e coloque na mesma pasta.
2. Abra o `index.html` no navegador. Pronto, está funcionando.

## 📱 Recursos incluídos

- ✅ Design responsivo (mobile, tablet, desktop)
- ✅ Menu hamburguer no mobile
- ✅ Botão flutuante WhatsApp

- ✅ SEO básico (meta tags)
- ✅ Estrutura semântica
